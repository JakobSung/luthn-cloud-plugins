# Luthn Cloud plugin 0.1

- Connects to `https://app.luthn.com/mcp` through browser OAuth.
- Binds the connection to one active member and workspace.
- Exposes safe-memory search and workspace status only.
- Does not advertise protected-original access, Hub-only writes, or automatic
  conversation capture.
- Requires no Node or Python runtime, native binary, API key, background
  process, or OS certificate.
